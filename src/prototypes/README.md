# UI explorations

## Selected 2026 direction

The image explorations in `images/` tested several fresh visual identities. **Cedar & Clay** was selected: an editorial, sentence-like conversion flow with a limestone background, cedar source values, clay results, sage controls, and restrained saffron accents. The selected direction was rebuilt in the production components with vanilla CSS; no prototype code is shipped.

## Archived exploration

This folder preserves the development-only A/B/C design exploration that led to the production **Calm Instrument** direction. It is intentionally disconnected from the application and should not be imported by production code.

- A — Calm Instrument (selected)
- B — Living Ledger
- C — Pocket Receipt

The later logo exploration selected **Dirham Compass**: the circular compass seal with a letter-free, curved exchange knot and a brass pivot. The selected mark was rewritten as `src/BrandMark.jsx`; the variants in this folder remain prototype-only reference material.
